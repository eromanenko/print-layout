## ⚙️ Рефакторинг та чистота коду (Clean Code)

- [ ] **Винесення вбудованих (inline) стилів з HTML:**
  - Повністю проаналізувати `index.html` на наявність атрибутів `style="..."`.
  - Створити семантичні CSS-класи в `css/style.css` та замінити ними вбудовані стилі.
  - Забезпечити збереження поточної поведінки розмітки при перенесенні стилів.

  - Визначити токени для відступів (`--spacing-xs`, `--spacing-sm`, `--spacing-md`, `--spacing-lg`), радіусів заокруглень (`--radius-sm`, `--radius-md`, `--radius-lg`), тіней (`--shadow-sm`, `--shadow-md`, `--shadow-lg`) та всіх кольорів (первинний, вторинний, фони, межі, тексти).

- [ ] **Централізоване керування станом (State Management):**
  - Створити централізований легковагий менеджер стану (наприклад, у `js/state.js` чи окремому сервісі).

  - Реалізувати автоматичне оновлення інтерфейсу при зміні стану без розкидання логіки оновлення UI по різних обробниках подій.
